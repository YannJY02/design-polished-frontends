# Delivery review

## 审查要点

Keep SKILL.md and agents/openai.yaml installable and consistent with the skill name. All bundled relative file links must resolve. Preserve the skill's authorization limits and evidence requirements: static screenshots or build success cannot prove native runtime or complete user journeys. Do not add credentials, personal data, remote execution hooks, or unconditional publishing. The packaged artifact must contain the skill, agent metadata, reference catalog and both READMEs. Source merge updates the Git installation source; it does not prove a consumer reinstalled it.
